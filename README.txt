## 主な機能
- 4人プレイヤー名入力
- 規則モード / 任意モード
- 18ホールの実スコア入力
- 前ホールから遡る同点順位判定
- 3パターンの自動ペア組み
- ペアA得点入力 → ペアBは自動反転
- ゲーム得点累計
- 実スコア合計
- 自動保存
- iPhoneホーム画面追加対応
- オフライン対応
- GOODS MONSTER 広告バナー
- GOODS MONSTER公式サイトへのリンク
- LINE問い合わせリンク
